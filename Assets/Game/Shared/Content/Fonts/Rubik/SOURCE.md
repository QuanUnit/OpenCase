# Rubik

- Licence: SIL Open Font License 1.1 (see `OFL.txt`).
- Source: https://github.com/googlefonts/rubik (official upstream, also used by https://github.com/google/fonts/tree/main/ofl/rubik).
- File: https://github.com/googlefonts/rubik/blob/main/fonts/variable/Rubik%5Bwght%5D.ttf
- Static instances generated from the variable font with fontTools (`fonttools varLib.instancer Rubik[wght].ttf wght=500` for `Rubik-Medium.ttf`, `wght=700` for `Rubik-Bold.ttf`, `--update-name-table`). Glyphs are unmodified; the upstream repository ships only the variable font.
- TMP assets: `RubikMedium SDF.asset`, `RubikBold SDF.asset` (dynamic atlas, Latin + Cyrillic glyphs are added on demand).
